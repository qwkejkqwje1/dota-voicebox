# Изменения

## Не выпущено (v0.5)
- **Режим «говорю только по кнопке»** (Пульт → «Микрофон в эфир»): «Всегда», «Пока держу кнопку», «Нажал — вкл / ещё раз — выкл». Совместим с Dota 2: с кнопкой голосового чата игры работает как обычно, со своей кнопкой (Mouse4, CapsLock…) VoiceBox сам зажимает кнопку чата игры. Плавное открытие без щелчков, «не обрывать конец фразы», звуки саундборда идут всегда. Действие `talk` для горячих клавиш, индикатор «🎙 ГОВОРЮ».
- **Любые виртуальные кабели**: Virtual Audio Cable («Line 1», «Line 2»…), VB-Cable и A/B/Hi-Fi, Voicemeeter (Input/AUX/VAIO3) и прочие — распознаются автоматически, «другой конец» кабеля подбирается сам. Любое устройство можно назначить кабелем вручную, плюс новое поле «Другой конец кабеля».
- Точное совпадение имени устройства важнее подстроки («Line 1» больше не путается с «Line 10»).
- Кабель больше не выбирается случайно как микрофон или наушники, если он стоит устройством по умолчанию.
- Предварительные сборки (`-dev`) получают релиз той же версии через автообновление.
- Автонастройка кабеля: проверка, что CABLE Input не стал устройством вывода по умолчанию (иначе звуки Windows идут в эфир) — кнопка «Вернуть наушники»; после установки VB-Cable прежнее устройство возвращается само.
- Частота кабеля 48 кГц: проверка и установка одной кнопкой (если Windows не даёт — открывается «Панель звука» с подсказкой).
- Сторож: уведомление, если кабель стал устройством по умолчанию.
- «Кто слушает микрофоны»: какие программы пишут звук и с какого устройства; кнопки «Проверить» для Discord и Dota 2.
- Тест «Проверить всё»: все проверки по очереди со сводкой.
- Диагностический пакет одним zip-файлом (журнал, конфиг, устройства, проверки, результаты тестов).
- VU-метры: шкала в dBFS, удержание пика, отметка перегруза (CLIP).

## v0.4.0 — «Пульт»
- VoiceBox теперь не только для Dota: общий пульт звука для Discord, игр, OBS и любых программ.
- Вкладка **«Пульт»**: полосы микрофона и дополнительных источников (входы аудиоинтерфейса по каналам, звук любого устройства через loopback), шины «Эфир» и «Мониторинг», индикаторы уровня на каждой полосе.
- На полосе источника: громкость, отправка в эфир и в наушники, «тише, когда говорю» (ducking), mute.
- Компенсация дрейфа часов между устройствами (адаптивный ресемплинг), счётчик опустошений буфера.
- Гейт микрофона и mute (действие `mic_mute` для клавиш).
- Визуализация голоса: осциллограмма, спектр, водопад, «до/после эффектов», порог гейта тянется мышью (бинарный WebSocket, 30 кадров/с).
- Вкладка **«Саундборд»** и **«Интеграции»**: Dota 2 (игра, таймеры, проверки, Рошан) и мастер Discord.
- Конфиг v2 с автоматической миграцией и резервными копиями (5 последних, восстановление из «Настройки»).
- **Автообновление** из GitHub Releases: проверка подписи ed25519, установка не во время матча, автоматический откат, если новая версия не запустилась, ручной откат кнопкой.

## v0.3.0
- Скрипты на JavaScript (goja) с редактором в программе: подсветка, номера строк, проверка ошибок на лету, справка со вставкой примеров, вывод скрипта. Изоляция и защита от зависаний.
- Комбинации клавиш: двойные нажатия, последовательности, аккорды, удержание; глобальный перехват без отбора клавиш у игры. Точное сравнение модификаторов.
- Скрипт «Ганк на миде» по умолчанию; примеры таймингов и событий.
- Надёжное игровое время: сглаживание, привязка фазы секунды, пауза, экстраполяция при потере пакетов, ручной горн/синхронизация, статус источника.
- GSI: больше данных (abilities, items, buildings, events), автообновление cfg, автоматический таймер Рошана по событию.
- Вкладка «Тест звука»: наушники, микрофон с рекомендацией усиления, кабель (уровень и задержка), пресет до/после, «как меня слышит команда», кнопка голосового чата.

## v0.2.0
- Интерфейс (окно WebView2): главная, звуки, таймеры, голос, клавиши, настройка, журнал.
- Автонастройка: поиск кабеля/микрофона, установка VB-Cable, GSI, параметр запуска Steam, кнопка голосового чата из биндов Dota 2.
- Watchdog: автоперезапуск аудио при появлении устройства, слежение за биндом PTT.
- Загрузка звуков перетаскиванием, озвучка текста, назначение клавиш нажатием.
- Редактор пресетов голоса с прослушкой на лету.
- Обратный отсчёт таймеров, индикаторы уровней, громкости на лету.
- Выравнивание громкости и срез тишины, кэш декодирования, повышенный приоритет, одна копия программы, автозапуск.
