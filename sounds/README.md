# Свои звуки

Проще всего — **перетащить файлы прямо в окно VoiceBox** (страница «Звуки»): подойдут MP3, WAV, OGG,
FLAC, M4A/AAC и Opus/WebM (всё, кроме MP3 и WAV, программа сама перекодирует в WAV). Файл появится плиткой на панели.

Можно и просто положить `.wav` или `.mp3` в эту папку — VoiceBox подхватит их **без перезапуска**.
ID звука = имя файла без расширения: `sounds/mid_gank.mp3` → `sound:mid_gank`.

Клавишу, громкость, значок, цвет и «кто слышит» удобнее настроить в программе: правый клик по плитке.
