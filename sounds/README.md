# Свои звуки

Проще всего — **перетащить файлы прямо в окно VoiceBox** (страница «Звуки»): подойдут MP3, WAV, OGG,
FLAC, M4A/AAC и Opus/WebM (всё, кроме MP3 и WAV, программа сама перекодирует в WAV). Файл появится плиткой на панели.

Можно и просто положить `.wav` или `.mp3` в эту папку — VoiceBox подхватит их **без перезапуска**.
ID звука = имя файла без расширения: `sounds/mid_gank.mp3` → `sound:mid_gank`.

Клавишу, громкость, значок, цвет и «кто слышит» удобнее настроить в программе: правый клик по плитке.

# Your own sounds

The easiest way is to **drop files right into the VoiceBox window** (the “Sounds” page): MP3, WAV, OGG,
FLAC, M4A/AAC and Opus/WebM work (everything except MP3 and WAV is converted to WAV by the app). The file appears as a tile on the pad.

You can also just put `.wav` or `.mp3` files into this folder — VoiceBox picks them up **without a restart**.
Sound ID = file name without the extension: `sounds/mid_gank.mp3` → `sound:mid_gank`.

Key, volume, icon, color and “who hears” are easier to set up in the app: right-click the tile.
