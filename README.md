# 🎙 Dota VoiceBox

Саундпад для Dota 2: звуки **в голосовой чат** по горячим клавишам, **пресеты искажения голоса**
(«дед инсайд», рация, мегафон, робот) и **звуковые таймеры рун** по игровому времени через
официальный Game State Integration.

Никакого вмешательства в игру: не читает память, не внедряется в процесс — только аудио,
горячие клавиши и официальный GSI от Valve.

## Возможности

- 🪟 **Интерфейс** — окно с вкладками: главная (пресеты, звуки, игровые часы, уровни), звуки, таймеры, голос, клавиши, настройка, журнал.
- ✨ **Автонастройка** — при первом запуске программа сама:
  - находит виртуальный кабель и микрофон (и переподключается, если устройство пропало/появилось);
  - скачивает и ставит **VB-Audio Virtual Cable** по одной кнопке;
  - находит Dota 2 во всех библиотеках Steam и ставит GSI-конфиг;
  - добавляет параметр запуска `-gamestateintegration` (аккуратно перезапуская Steam, с резервной копией);
  - **читает кнопку голосового чата из биндов Dota 2** и следит за её изменением.
- 🔊 Звуки в войс по глобальным горячим клавишам (работают поверх игры), ваш голос идёт как обычно.
- 🚨 Встроенная **сирена** «мид ганкают»: `Num1` — сирена, `Num1 Num1` — сирена + голос «Мид, ганк!», `Ctrl+Num1` — «Мид пропал!» (скрипт `gank_mid`).
- ⚡ **Скрипты на JavaScript** прямо в программе (вкладка «Скрипты»): редактор с подсветкой, проверкой ошибок
  с номером строки и справкой. Свои тайминги, комбинации клавиш (двойные нажатия, удержание, аккорды),
  реакции на события и состояние героя. Каждый скрипт изолирован: ошибка или бесконечный цикл не ломают программу.
- 🕐 **Надёжное игровое время**: сглаживание между пакетами GSI, привязка к смене секунды, учёт паузы,
  продолжение отсчёта при пропаже пакетов (до 90 с), защита от «отката» времени; источник и частота пакетов
  видны на главной. Без GSI — кнопка **«Горн 0:00»** или ручная синхронизация. Рошан засекается **автоматически**
  (событие GSI `roshan_killed`).
- 🩺 **Тест звука и голоса**: наушники, микрофон (уровень речи, фон, перегруз, подбор усиления),
  кабель → Dota (тон через кабель с замером уровня и задержки), пресет «до/после», «как меня слышит команда»
  (запись с другого конца кабеля), проверка кнопки голосового чата.
- ⏱ Таймеры по игровым часам Dota: **руна мудрости (экспа)** каждые 7:00 и **руна в миду на 6:00**;
  силовые, баунти-руны и стаки — включаются одной галочкой. Пауза и переподключение не сбивают таймеры.
  Обратный отсчёт до ближайших событий — на главной.
- 🐉 Таймер Рошана: аегис 5:00, окно респауна 8:00–11:00.
- 🎛 Пресеты голоса, переключаются на лету, плюс **редактор пресетов** с прослушкой «на лету»:

  | Пресет | Звук |
  |---|---|
  | `clean` | чистый голос |
  | `dead_inside` | передавленный, перегруженный микрофон с раздутым басом |
  | `dead_inside_max` | ушная боль: жёсткий клиппинг, 6 бит, заворот волны |
  | `radio` | рация: полоса 350–3200 Гц, щелчок в начале фразы, шипение, «хвост» в конце |
  | `radio_broken` | рация с плохим приёмом: треск, выпадения, цифровая грязь |
  | `megaphone` | громкоговоритель |
  | `robot` | робот (кольцевая модуляция) |

- 📁 Свои звуки: перетащите `.mp3`/`.wav` в окно (или в папку `sounds/`) → назначьте клавишу или событие.
  Громкость выравнивается автоматически, тишина в начале файла срезается.
- 🗣 Озвучка текста (Windows TTS) прямо из интерфейса.
- 🎮 Звуки на события игры: смерть, килл, серия, низкое HP, 6 уровень, смок, день/ночь, победа/поражение.
- 🎧 Самопрослушка — слышать свой обработанный голос, чтобы подобрать пресет. Индикаторы уровней.
- ⌨️ Автонажатие кнопки голосового чата, пока играет звук (не мешает, если вы держите её сами).
- ⚡ Оптимизация: обработка без выделений памяти в аудиопотоке, кэш декодированных звуков,
  повышенный приоритет процесса, одна копия программы, автозапуск с Windows (в фоне).

## Установка

1. Скачайте `dota-voicebox-…-windows.zip` из [Releases](../../releases) (или артефакт последней сборки в **Actions**), распакуйте.
2. Запустите `voicebox.exe` → откроется окно, вкладка **«Настройка»** → **«Настроить всё автоматически»**.
3. Единственный ручной шаг (один раз): Dota 2 → Настройки → Звук → **Устройство ввода: `CABLE Output`**.

Нужен WebView2 (есть в Windows 10/11). Если его нет — интерфейс откроется в браузере.

```
Микрофон ──► [пресет голоса] ──┐
                               ├──► CABLE Input ──► Dota 2 (микрофон = CABLE Output)
Звуки (войс) ──────────────────┘
Звуки (напоминания) ─────────────► ваши наушники
```

## Горячие клавиши по умолчанию

| Клавиша | Действие |
|---|---|
| `Num1` / `Num1 Num1` / `Ctrl+Num1` | 🚨 сирена / сирена + «Мид, ганк!» / «Мид пропал!» (скрипт) |
| `Num2` / `Num3` | сообщить команде про руну мудрости / руну на 6:00 |
| `Num0` | чистый голос |
| `Num4`…`Num9` | dead_inside, dead_inside_max, radio, radio_broken, megaphone, robot |
| `Num+` | следующий пресет |
| `Num-` | Рошан убит (запуск таймеров) |
| `Num*` | самопрослушка вкл/выкл |
| `Num.` | остановить все звуки |
| `Num/` | перечитать конфиг |
| `Ctrl+Alt+V` | открыть окно (если программа работает в фоне) |

Формат: `"Ctrl+Alt+F9"`, `"Shift+Num1"`, `"F13"`.
Действия: `sound:<id>`, `sound:<id>@both|voice|monitor`, `preset:<имя>`, `preset:next`, `preset:prev`, `stop`, `rosh`, `mic_monitor`, `reload`, `clock_horn`, `clock_sync:12:34`.

## Скрипты

Файлы `scripts/*.js` рядом с программой (включаются галочкой во вкладке «Скрипты»). Пример:

```js
// Ганк на миде
combo("Num1 Num1", () => {
  play("siren", { to: "team" });
  say("Мид, ганк!", { to: "team" });
}, { within: 400 });

at("6:00", () => say("Руны!", { to: "me" }), { before: 10 });
every("7:00", (t) => notify("Мудрость в " + fmt(t)), { before: 20 });
on("death", () => play("beep", { to: "me" }));
```

API: `hotkey`, `combo`, `hold`, `onKey`, `at`, `every`, `on`, `after`, `repeat`, `cancel`, `play`, `say`, `stop`,
`preset`, `action`, `notify`, `log`, `time`, `fmt`, объект `game` (`clock`, `seconds`, `hero`, `paused`, `daytime`,
`state`, `clockSource`, `raw` — весь JSON от Dota). Полная справка — во вкладке «Скрипты».

## Конфиг

Всё настраивается в интерфейсе; `config.json` можно править и руками — изменения подхватываются на лету.
Полный пример — [`config.example.json`](config.example.json). Главное:

### Звуки

```json
"sounds": {
  "siren":    { "files": ["builtin:siren"], "bus": "both", "cooldown": 3, "mode": "interrupt" },
  "gank":     { "files": ["sounds/gank1.mp3", "sounds/gank2.mp3"], "volume": 0.8 },
  "mid_miss": { "files": ["tts:Мид пропал!"], "bus": "voice" }
}
```

- `files` — несколько файлов = случайный выбор. Источники: путь к файлу, `builtin:<имя>`, `tts:<текст>`.
- `bus`: `both` — команде и вам, `voice` — только команде, `monitor` — только вам.
- `mode`: `overlap` (накладывать), `interrupt` (перезапустить), `ignore` (не запускать, пока играет).
- `cooldown` — секунды между повторами (антиспам).
- Встроенные: `siren`, `wisdom_rune`, `mid_rune_6`, `power_rune`, `bounty_rune`, `rosh`, `stack`, `beep`, `danger`.
  Послушать/взять за основу: `voicebox.exe -export-sounds builtin_wav`.

### Таймеры

```json
"timers": [
  { "id": "mid_rune_6",  "sound": "mid_rune_6",  "at": [360], "warn_before": 10 },
  { "id": "wisdom_rune", "sound": "wisdom_rune", "start": 420, "every": 420, "warn_before": 20 },
  { "id": "power_rune",  "sound": "power_rune",  "start": 360, "every": 120, "skip": [360], "warn_before": 10, "disabled": true }
]
```

Время — секунды игровых часов. Интервалы рун меняются от патча к патчу — правьте здесь, без пересборки.

### События

```json
"events": { "death": "sad_trombone@both", "streak_3": "rampage", "low_hp": "low_hp" }
```

Доступно: `game_start`, `pregame`, `kill`, `death`, `respawn`, `streak_3`, `streak_5`, `streak_10`,
`low_hp`, `level_6`, `smoked`, `day`, `night`, `victory`, `defeat`.

### Свои пресеты голоса

```json
"voice_presets": {
  "my_bass": [
    { "type": "gate", "threshold_db": -50 },
    { "type": "lowshelf", "freq": 150, "db": 10 },
    { "type": "gain", "db": 15 },
    { "type": "drive", "amount": 0.8, "mode": "soft" },
    { "type": "limiter", "threshold_db": -1 }
  ]
}
```

Эффекты: `gain`, `lowpass`, `highpass`, `bandpass`, `peaking`, `lowshelf`, `highshelf`,
`drive` (`soft|hard|fold`), `bitcrush`, `compressor`, `gate`, `squelch` (рация), `noise` (`white|crackle`),
`dropout`, `ringmod`, `limiter`. Встроенный пресет можно переопределить, задав его имя.

## Сборка

Нужен Go 1.22+ и компилятор C (cgo для miniaudio): на Windows — [MSYS2/mingw-w64](https://www.msys2.org/) или TDM-GCC.

```bash
go test ./...
go build -o voicebox.exe ./cmd/voicebox
```

CI (GitHub Actions) собирает `voicebox.exe` на каждый push; тег `v*` создаёт релиз.

## Структура

```
cmd/voicebox        точка входа, флаги
internal/audio      движок (malgo/miniaudio): дуплекс мик→кабель, наушники, микшер
internal/dsp        эффекты и пресеты голоса
internal/sounds     WAV/MP3, встроенные синтезированные звуки, библиотека
internal/timers     таймеры по игровому времени
internal/gameclock  сглаженное игровое время (GSI + экстраполяция + ручной режим)
internal/script     скрипты на JS (goja): клавиши, комбинации, тайминги, события
internal/combo      распознавание комбинаций, двойных нажатий и удержаний
internal/gsi        приём GSI и игровые события
internal/winapi     горячие клавиши, эмуляция PTT, TTS, поиск Dota 2
internal/app        связка всего, автонастройка, watchdog, горячая перезагрузка
internal/ui         интерфейс: локальный API + SSE, окно WebView2, static/ (HTML/CSS/JS)
internal/logbus     журнал для интерфейса
```

Интерфейс — локальный сервер `127.0.0.1:3001` с одноразовым токеном доступа (сайты в браузере не могут управлять программой).

## Честная игра

Не спамьте: у звуков есть `cooldown`, а тиммейты могут вас замьютить или зарепортить.
Напоминания таймеров по умолчанию слышите только вы.
